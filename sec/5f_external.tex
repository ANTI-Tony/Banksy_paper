\subsection{External benchmarks}
\label{sec:exp_external}
We re-ran both external benchmarks with the frozen final system (B1, the configuration of \cref{tab:main}, run from a code snapshot), keeping the earlier runs with a superseded front end only as history (supplement). Neither benchmark matches our task exactly, so we state what each method receives.

\paragraph{Editing correct text (VTE-Bench Real).} The 100 real clips of \steer's own benchmark~\cite{zeng2026steervte} ask to change correct text into a different string. \method receives the source clip, the target string, the source string (used only to locate the text by OCR) and the benchmark's text mask as hint box; \steer receives the mask, a rendering of the target and an image of the source style, following its official protocol. In 8 of the 100 clips the frozen front end does not find enough detection boxes inside the hint and ships the clip unchanged, as it would in deployment; these clips are scored as unchanged and listed in the supplement. \pending{[Readability (both readers), EasyOCR, background and temporal results pending.]}

\paragraph{Commercial video models (VidScribe).} VidScribe~\cite{vidscribe2026} releases the outputs of seven commercial video models for video-to-video text editing. We use the 44 of its 93 clips whose operation is a replacement, translation or deletion and whose source text can be located by OCR (27 style-only and 9 insertion clips are excluded by operation, 13 by localisation); \method receives the source clip, the target string, the source string and the located box, whereas the commercial models were prompted with an instruction and receive no box. One clip is not located by the frozen front end and is shipped unchanged. Deletions have an empty target, so readability is undefined for them: we report readability on the 29 replacement and translation clips, and for the 15 deletions the share in which the source string is no longer read (similarity below 0.5 in at least 4 of 5 frames). \pending{[Results pending.]}
