\caption{\textbf{\method overview.} Bottom: intermediate results of the frozen pipeline on an illustrative benchmark clip (garbled \str{PHARMATCA}, target \str{PHARMACY}), cropped from one reference frame: (a) input with the OCR box (dashed red) and the accepted glyph instance (green); (b) the band erased with LaMa; (c) the box layout used as fallback; (d) the instance layout, rendered deterministically; (e) after SAT. Three evidence gates decide how much to change: the preservation gate keeps a clip whose text already reads the target, the localization gate chooses between the old glyph instance and the tracked box, and the appearance gate enables SAT where it measurably helps. The target is rendered deterministically and composited only inside the text region. All results attributed to \method (B1) are produced by this training-free pipeline; hybrid and exploratory variants are evaluated separately.}
