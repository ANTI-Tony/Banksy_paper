\caption{\textbf{\method overview.} Three evidence gates decide how much to change. The preservation gate returns the input unchanged when multi-frame OCR already reads the target; the localization gate chooses between laying the new text out on the old glyph instance and filling the tracked box; the appearance gate enables source appearance transport (SAT) only on emissive carriers where it measurably reduces the reconstruction error. The target string is always rendered deterministically, so its spelling cannot drift, and only pixels inside the text region are composited. Every result in this paper is produced by this pipeline; nothing is trained.}
